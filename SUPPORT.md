# Getting help

| You want to… | Go to |
| :-- | :-- |
| Read the documentation | [dialectic-playground.github.io/docs](https://dialectic-playground.github.io/docs/) |
| Ask a question or discuss an idea | [Organization discussions](https://github.com/orgs/dialectic-playground/discussions) |
| Report a bug or request a change | The **Issues** tab of the repository concerned (use the issue forms) |
| Report a security vulnerability | Private vulnerability reporting; see [SECURITY.md](SECURITY.md) |
| Report a Code of Conduct concern | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-an-issue) |

Please search existing discussions and issues before opening a new one.
